## Project Overview

AIOps platform using NLP and machine learning to automatically classify incidents, correlate alerts, and suggest resolutions based on historical patterns. Features BERT-based text classification and FastAPI backend.

**Role**: IT Operations Specialist
**Organization**: ACORIA
**Duration**: January 2019 - May 2019
**Project**: #18 of 30 in IT Career Portfolio

## Business Impact

- **90% Incident Classification Accuracy**: BERT-based NLP model
- **65% Reduction in Alert Noise**: Intelligent alert correlation
- **Automated Resolution Suggestions**: Based on historical patterns
- **45% Faster MTTR**: AI-assisted incident management

## Technology Stack

- **Python 3.7**: Core application
- **TensorFlow 2.0**: Deep learning framework
- **BERT**: Pre-trained NLP model for text classification
- **FastAPI**: High-performance API framework
- **Redis**: Caching and alert correlation
